# 如何使用本程序寻找兼职岗位

## 背景

在平台勾选「兼职」选项后，实际推荐列表里仍以全职岗位为主。本程序把求职类型作为显式筛选项，只对匹配兼职类型的岗位发起投递。

## 适用范围

该筛选在 **Boss 直聘** 平台上生效。其他平台的投递逻辑尚未接入该筛选条件。

## 使用方法

1. 启动程序，在网页端进入 Boss 配置页。
2. 在「求职类型」中选择 `兼职`。
3. 在「期望岗位 / 关键词」中填写目标岗位，例如 `前端实习`、`数据标注`。
4. 按需设置期望薪资区间与期望城市。
5. 保存配置后启动投递任务。

程序会按上述条件筛选岗位，只对符合条件且未被过滤（黑名单、薪资不达标、HR 不活跃等）的岗位发起打招呼。

## 说明

- 兼职岗位数量通常少于全职，建议配合较宽松的薪资区间与多个关键词。
- 投递频率受平台限制，请合理设置 `wait_time` 降速，避免触发风控。
- 每个岗位的投递结果会记录在数据库，可通过投递分析页面查看。
